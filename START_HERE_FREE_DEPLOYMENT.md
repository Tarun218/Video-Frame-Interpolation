## 🚀 Your Quick Path to Live (3 Simple Steps)

### Step 1️⃣: Push to GitHub

```bash
cd "d:\Projects\Video Frame Interpolation\Video Frame Interpolation"
git init
git add .
git commit -m "Video Frame Interpolation - Ready for Render"
git remote add origin https://github.com/YOUR_USERNAME/Video-Frame-Interpolation.git
git push -u origin main
```

✅ **Done**: Your code is on GitHub

---

### Step 2️⃣: Create Free Render Account

1. Go to **[render.com](https://render.com)**
2. Click **"Sign up"** → **"Sign up with GitHub"**
3. Authorize & done!

✅ **Done**: Render account is ready (1 minute)

---

### Step 3️⃣: Deploy from Render Dashboard

1. In Render, click **"New +"** → **"Web Service"**
2. Click **"Connect a repository"**
3. Find & select your repo
4. Fill in:
   - **Name**: `video-interpolation-studio`
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Plan**: `Free`
5. Click **"Create Web Service"**
6. Wait 5-10 minutes for build to complete

✅ **Done**: Your app is LIVE FOR FREE! 🎉

## 🔄 Auto-Deploy (Optional)

To auto-deploy when you push to GitHub:

1. Render Dashboard → Your service → **Settings**
2. Find **"Auto-Deploy"**
3. Select **"main"** branch
4. Save

Now every `git push origin main` automatically updates your live app!
