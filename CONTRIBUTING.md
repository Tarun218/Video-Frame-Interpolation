# Contributing

Thank you for your interest in contributing to Video Frame Interpolation Studio.

## How to contribute

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your feature or fix.
4. Make your changes and ensure the project still runs.
5. Submit a pull request with a clear description.

## Development

Install dependencies:

    npm install

Run the application:

    npm start

## Code style

- Keep code readable and well-formatted.
- Add comments for non-obvious logic.
- Keep documentation up to date.

## Issues

If you find a bug or want an improvement, please open an issue in the repository.
